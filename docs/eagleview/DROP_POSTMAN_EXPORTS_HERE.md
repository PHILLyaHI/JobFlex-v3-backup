# EagleView API — drop your Postman exports here

Save your exported EagleView Postman file(s) into this folder (`docs/eagleview/`).
Keep Postman's default names, or use these:

- `docs/eagleview/collection.postman_collection.json`   ← the Measurement Orders / API collection
- `docs/eagleview/environment.postman_environment.json` ← the Sandbox **environment** (has base URLs + auth vars — most important)

If the portal gave you several collections (Authentication, Measurement Orders,
Property Data, Imagery/WMTS), drop **all** of them here. Any filename ending in
`.json` is fine — Claude will read whatever is in this folder.

Then tell Claude: "exports are in docs/eagleview/".
