## Три недостроенных места и план по ним

### 1. Smart Proposal — заглушки (самое простое: код, без ключей, ~пара часов)
- «Send to proposal» — подключить к существующему convert-экшену (паттерн Roof/Fence:
  создать proposal → redirect). Работает и на фолбэк-смете без OpenAI.
- 5 стрелок материалов (`.sp-req-link`) — нужно продуктовое решение владельца:
  (а) поиск поставщика по материалу · (б) копировать заявку в буфер · (в) убрать кнопки.

### 2. Settings — персист (средне, ~день на v1)
- v1 (согласовано, не начато): Account-панель — имя/телефон юзера + бизнес-поля организации,
  БЕЗ адреса и трейдов (они питают лид-матчинг, геокодинг требует Google-ключ);
  реальные busy/disabled на SaveBar; переиспользовать существующие экшены.
- Notifications: нужна миграция схемы (поле предпочтений) — отдельное «да» владельца;
  сначала prefs будут write-only, подключение к отправке писем — следующий шаг.
- Danger-zone Delete — оставить инертным.

### 3. Subscription — оплата (~день при наличии ключей)
Бэкенд уже наполовину есть: Organization.plan, каталог планов (limitsJson),
StripePriceMirror, planStripeSync/stripeSync, вебхук /api/webhooks/stripe,
cron reconcile-stripe, план-лимиты уже enforce'ятся (ensureWithinLimit).
Осталось: заменить фикстуры страницы на реальные данные (план/лимиты/usage/счета),
повесить CTA тарифов на checkout, прогнать синк цен в Stripe TEST mode.
Пререквизит: Stripe TEST-ключи + `stripe listen --forward-to localhost:3000/api/webhooks/stripe`.

Рекомендованный порядок: Smart Proposal → Settings v1 → Subscription.
